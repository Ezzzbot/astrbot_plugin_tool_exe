# 大头的工具箱

一个按功能模块持续扩展的 AstrBot 工具箱插件。

## 功能

| 指令      | 别名                  | 说明                             |
| ------- | ------------------- | ------------------------------ |
| `/今日新闻` | `60s`、`新闻60秒`、`看世界` | 60 秒读懂世界每日新闻速览                 |
| `/运势`   | `今日运势`、`抽签`        | 今日运势，同一人同一天结果固定，次日自动刷新 |

## 安装

插件页面右下角提供GitHub网址手动安装。

## 配置

**WebUI 插件配置页**：

| 配置项   | 说明                          |
| ----- | --------------------------- |
| 启用该功能 | 分「今日新闻」「今日运势」两组，各自独立开关      |
| 接口地址  | 默认 60s API，一般不用改           |
| 发送形式  | 纯文本 / 长图 / 图文一起发            |

## 常见问题

**提示「接口限流了（HTTP 429）」**：接口对短时间内的重复请求有限制，默认缓存 10 分钟，稍等或调大 `cache_seconds`。

**群里一直没反应**：确认「今日新闻」开关已开启，并检查 AstrBot 日志里 `[tool_exe]` 开头的报错。

**图片发不出去**：部分平台对超长图支持不好，把发送形式改回「纯文本」。

**访问接口慢或失败**：在 `config.yaml` 里填 HTTP 代理。

**运势每次都不一样吗**：不会。同一个人的当天结果固定，同一个人连发两次必然一样，换一天才变。

## 数据来源

- 每日新闻：[60s API](https://github.com/vikiboss/60s)（作者 vikiboss）
- 今日运势：本地哈希计算，不调用任何接口
