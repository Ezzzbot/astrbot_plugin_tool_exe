# 大头的工具箱

一个按功能模块持续扩展的 AstrBot 工具箱插件，目前包含每日新闻速览。

## 功能

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/今日新闻 [条数]` | `60s`、`新闻60秒`、`看世界` | 60 秒读懂世界每日新闻速览，不带条数则输出当天全部 |
| `/工具箱` | `toolbox`、`功能列表` | 列出当前可用功能 |

也可以直接对 Bot 说「今天有什么新闻」，由 LLM 自动调用同一功能。

## 配置

**WebUI 插件配置页**：

| 配置项 | 说明 |
| --- | --- |
| 启用该功能 | 今日新闻的开关 |
| 接口地址 | 默认 60s API，一般不用改 |
| 发送形式 | 纯文本 / 长图 / 图文一起发 |

**根目录 `config.yaml`**（改完在插件页点重载生效）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `network.timeout` | 10 | 单次请求超时（秒） |
| `network.retries` | 2 | 失败重试次数 |
| `network.proxy` | 空 | HTTP 代理，如 `http://127.0.0.1:7890` |
| `news60s.cache_seconds` | 600 | 数据缓存时长（秒），0 表示不缓存 |
| `news60s.show_meta` | true | 显示日期 / 星期 / 农历 |
| `news60s.show_tip` | true | 显示每日微语 |
| `news60s.show_link` | true | 显示原文链接 |
| `news60s.footer` | 空 | 自定义落款 |

同名配置以 WebUI 为准；`config.yaml` 缺失也能正常运行。

## 常见问题

**提示「接口限流了（HTTP 429）」**：接口对短时间内的重复请求有限制，默认缓存 10 分钟，稍等或调大 `cache_seconds`。

**群里一直没反应**：确认「今日新闻」开关已开启，并检查 AstrBot 日志里 `[tool_exe]` 开头的报错。

**图片发不出去**：部分平台对超长图支持不好，把发送形式改回「纯文本」。

**访问接口慢或失败**：在 `config.yaml` 里填 HTTP 代理。
